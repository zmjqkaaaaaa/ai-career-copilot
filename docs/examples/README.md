# 功能示例导读

这个目录记录了 AI Career Copilot 四个功能的演示和验收案例。输入是合成材料或公开代码，适合开发者看流程、核对输出。想了解产品核心流程，可以直接打开[个人实测案例](../stage11/PERSONAL_RESUME_REMATCH.md)。

| 文件 | 用一句话理解 | 可以先看什么 |
| --- | --- | --- |
| [竞品研究示例](discovery-competitor.md) | 假设有人要整理无人机巡检记录，比较手工表格和自动化工作流各适合什么。 | 看表格里的「与本场景的关系」，了解如何区分已知功能和待验证需求。 |
| [模拟面试复盘示例](interview-review.md) | 用一份虚构答卷演示系统如何追问、点评和布置练习。 | 看「复盘和训练」，了解系统怎样把答题遗漏转成练习。 |
| [SQL 学习导师示例](learning-sql.md) | 两个岗位分别关联两条和一条技能，连表得到三行，实际仍是两个岗位。 | 看「导师与固定样例」，了解导师怎样引导用户区分行数和岗位数。 |
| [项目代码教学示例](project-mentor-queue.md) | 用一段开源代码展示系统如何解释「排队时先来的人先离开」，再检查用户是否理解边界情况。 | 看「架构与函数解释」，了解讲解如何回到源码核对。 |
