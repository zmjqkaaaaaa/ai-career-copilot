# 成长导师验收示例 · SQL 一对多关联

## 路线与任务

合成用户的学习目标是「练习 SQL 关联与聚合」，每周 140 分钟。实际生成的路线先安排 SQL，再展开其他课程，用户研究排在 PRD 前。课程总量约 2.9 周，每天约 20 分钟。本次可以先手算固定样例，后续再写查询和核对结果。

## 导师与固定样例

设 P1 有两条技能，P2 有一条技能。按岗位关联技能后，行数为 3，按岗位主键去重后的岗位数为 2。两轮教学先让用户指出重复行来源，再追问统计岗位数与统计每个岗位技能数各自的聚合层级。该例引用了本项目 `learning.py` 中的 `progress` 函数，展示直接对任务表计数的逻辑。填报 3 和 2 可由应用直接核对。

## 人工复核

字面上，`COUNT(*)` 统计当前查询结果行。若 `jobs` 已经是一行一岗位，按方向分组时直接使用 `COUNT(*)` 即可。只有查询粒度变化，例如一对多关联展开岗位时，才应根据统计口径对 `job_id` 去重。方向字段是分组维度，不能拿它给岗位去重。复盘时同时给出表结构、固定输入、期望值与异常用例，便于他人复现。模型生成的 SQL 建议需要对照实际字段和关联方式。

真实百炼的路线、对话和作业反馈保存在本机 `work/phase8/live-learning.json`。

最终复测得到作业参考分 68.75，证据覆盖率 80%，固定样例两项均匹配。反馈要求补充表粒度、主键和一组 JOIN 后重复数据，保留「待修订」状态。
