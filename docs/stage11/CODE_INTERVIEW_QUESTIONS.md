# AI Career Copilot 技术面试问题

围绕具体实现作答。每个主问题练习 60–90 秒，追问再用代码说明。答题时明确需求和取舍、证据、验证边界。你可以说明 Codex 参与开发，再指出你实际提出、确认或能独立验证的工作。

## 认证

1. 从邮箱登录到读取私有简历，浏览器和 FastAPI 在哪些步骤验证什么？
2. JWT、Argon2、数据库唯一键各解决哪种问题？若有人复制了已签发令牌，当前系统如何限制其使用？
3. 追问：如何用两个测试账号独立检验归属检查？

## 文件上传

1. 为什么把上传、本地解析、AI 提取拆成三步？每步给前端什么状态？
2. 如果 PDF 只有图片，当前系统怎样处理？什么时候需要引入 OCR？
3. 追问：能否用一条测试证明失败时没有留下原件或有效记录？

## LLM 接入

1. 从点击确认到看到结果，API Key、Prompt、任务表、Worker 和模型分别在哪里？
2. 模型超时或限流时，怎样区分可恢复问题和必须重新确认的资料变化？
3. 追问：如何测 Token 与费用，缺少单价或用量时怎样汇报？

## 结构化输出

1. 举一个 JSON 格式合法、但业务上不可接受的真实例子。
2. `json_object`、Pydantic 校验与领域引文审核分别何时发生？
3. 追问：怎样对新旧提示词进行回归，避免被单条样例误导？

## 岗位匹配

1. 翻译成产品语言，什么交给模型、什么交给规则？请举一项加分要求与一项硬门槛。
2. 给定两份覆盖率不同的报告，如何解释分数？用户改一个简历条目后如何验证改动确实有用？
3. 追问：硬性要求不满足时，为什么不能直接按总分给建议？

## 仓库理解

1. 为什么用 commit 和行号？项目里的检索怎样找证据？
2. 项目有向量库或自主 Agent 吗？当前固定流程能做什么，何时会找错证据？
3. 追问：如何拿一段固定代码及反例验收模型解释和引用？

## 模拟面试

1. 给出一次动态追问何时被接受以及何时被拒绝的例子。
2. 一轮作答涵盖一半维度时，报告怎样处理未评估范围？
3. 追问：前端刷新、重复提交、后台晚到结果分别靠哪些可追溯状态处理？

## 数据库

1. 说清楚用户、岗位、简历内容、匹配报告和差距之间的主外键。
2. 为什么报告和差距应在同一事务中保存？什么时候需要 flush？
3. 追问：在一对多 JOIN 后统计报告数量，怎样避免被重复行误导？怎样检查索引实际是否有用？
