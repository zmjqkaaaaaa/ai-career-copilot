# AI Career Copilot 演示脚本

**成片目标 4 分 20 秒**。围绕一份合成简历、同一份 AI 产品实习 JD 和同一个演示账号串联。画面用实际页面；有等待的模型步骤可事先在隔离环境完成，录制时展示该任务历史和结果，字幕标注「预先生成的合成示例」。

## 录制前准备

- 准备两版合成简历。第一版只写“整理招聘看板数据”，第二版补上该演示项目的具体操作，例如“按岗位 ID 去重后核对岗位计数”。两份版本先在职业画像中分别确认。选择一份来源明确的合成 JD，保持其修订号不变。
- 在测试后端准备同一账号的首次、再次匹配报告和一个已选项目。为项目保存一份 PRD 版本、一个可回查固定提交的公开仓库快照和一份模拟面试报告。先核对报告可见字段和链接。
- 运行方式见 [本地启动](README.md#本地运行)。实录仅使用合成账号与资料。GitHub 配额不足时展示已保存的提交，或使用项目历史验收中的受控仓库；说明其来源。当前没有外部服务时，可使用现有受控验收证据及截图呈现对应界面。
- 开始前确认投递记录为合成数据，不操作外部招聘网站。画面不包含个人邮箱、Token、API Key 或真实简历。
