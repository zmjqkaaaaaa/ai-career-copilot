# AI Career Copilot · 三版简历项目经历

日期与仓库公开链接可按本人核实过的信息填写。每次投递选择最贴近目标 JD 的一版。项目角色统一为项目发起人、产品负责人。技术实现通过 Codex 协作完成。

## 1. AI 产品经理实习方向

**AI Career Copilot｜AI 求职成长助手｜项目发起人 / 产品负责人**

- 从本人投递受挫及一位同学的面试个案出发，聚焦做过项目但缺少对口实习的学生。基于公开产品说明对照 JD 匹配、简历改写和版本管理场景。
- 定义“职业画像—JD 诊断—优先差距—修订复查”任务，并提出以首次读完报告后 48 小时内在同一 JD 复查改动、能解释证据变化作为试用指标。
- 通过 Codex 协作落地结构化简历、规则匹配和证据展示。项目的合成账号验收核对了报告、项目、面试和投递之间的资料来源；48 小时指标待真人试用。

## 2. AI Agent 产品经理实习方向

**AI Career Copilot｜面向求职准备的 AI 工作流产品｜项目发起人 / 产品负责人**

- 定义 JD 解析、证据确认、匹配、项目探索与面试复练的阶段和交接信息，明确哪些步骤需要用户确认，哪些结果可进入后续任务。
- 通过 Codex 协作实现固定工作流和异步状态处理。模型提供抽取、讲解和拟议追问；程序负责归属、版本、匹配评分、流程推进及失败反馈。当前实现采用代码预定的工具与步骤。
- 设计与实际证据对齐的质量说明。历史真实模型基线覆盖 12 条合成样本，12 条结构通过、9 条过全部业务检查。失败案例用于复核分类、保守改写和评分边界。

## 3. AI 应用产品经理实习方向

**AI Career Copilot｜从目标岗位到项目与面试准备｜项目发起人 / 产品负责人**

- 将目标岗位拆成候选人需要证明的能力，设计 JD 原句、简历证据、优先差距和下一步行动的呈现，覆盖诊断、项目练习和投递复盘。
- 通过 Codex 协作构建可运行的 Web 原型。接通 PDF/DOCX 本地解析、结构化模型输出、公开 GitHub 提交证据和多轮面试，设置外发确认及失败恢复。
- 项目以隔离 MySQL、Edge、合成账号和受控模型测试串联流程。历史全量回归 120 项通过、10 项跳过。该结果反映本机验证范围。

## 归属与面试核对

| 证据类型 | 可以陈述的内容 |
| --- | --- |
| 本人提出 | 项目来源、目标用户、职业画像与 JD 联合诊断、差距优先级、48 小时复查定义 |
| 本人参与推进 | 编写需求、确认阶段方案、组织 Codex 协作、审阅产品与文档 |
| Codex 辅助与仓库工程成果 | 当前代码、自动化测试、架构及部分文档整理。个人独立实现或亲自完成的测试需有可核实证据 |
| 待验证 | 真实用户人数、真实转化、面试邀请改善、生产上线、商业价值 |
