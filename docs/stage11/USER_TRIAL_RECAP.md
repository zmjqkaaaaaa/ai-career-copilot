# 首轮用户试用与产品迭代

2026 年 11 月 25 日整理。首轮记录覆盖三位参与者，包括一次项目负责人自测和两位同学试用。场景包括准备 AI 产品实习、核对岗位要求和评估跳槽机会。资料来自负责人自述、同学反馈转述以及本地功能复核。

## 试用发现

| 观察 | 产品判断 |
| --- | --- |
| 负责人和一位同学都认可 JD 的逐项拆解。其中一位明确认可把岗位要求和经历对照。 | 保留逐项核对，优先改善证据关联和下一步提示。 |
| 负责人阅读报告后精简了简历，并开始为项目补充真实案例。项目验证完成后的简历复查尚待记录。 | 目前有一次从报告到实际修改的自测记录。同一 JD 的二次匹配仍需观察。 |
| 有同学在报告末尾点击生成建议，随后需要到页面顶部确认发送。该环节的整体评价一般。 | 优先缩短确认路径。建议本身能否转成行动，需要另做复测。 |
| 个别文件出现实习与项目归类问题，另有一份 PDF 在阅读器里显示正常但中文无法解析。报告大面积显示「待评分」时，也容易被理解为没有相关能力。 | 修复文件读取和分类，再把有证据、待核实和无适用门槛分别说明。 |

## 已完成的修改

| 反馈 | 实现 | 验证 |
| --- | --- | --- |
| 实习归类偏差、正文遗漏 | 本地先识别原文标题和经历，保留完整正文。提供待确认草稿，AI 提取保留可核对的章节证据。 | 用原试用文件在本地核对了实习与项目分组。 |
| PDF 中文文字层异常 | 对声明 Adobe-GB1、缺少 Unicode 映射的横排 PDF 补充标准字符映射。 | 原试用文件的两页中文恢复可读，成功生成包含正式工作和实习经历的草稿。 |
| JD 匹配漏掉相关教育和正式工作 | 匹配读取已确认的教育、工作与实践证据。相关背景提供间接佐证，难以直接判断的行为提示面试核实。同步调整 JD 与职业画像提示词。 | 同一份已确认简历和 JD 本地复算后回查原文，新提示词也通过合成材料的真实模型调用。 |
| 求职建议失败、发送确认离按钮太远 | 格式异常时有一次纠正重试，仍失败则提供明确标识的本地建议。预览、确认、进度和结果放在同一报告区域。 | 自动化覆盖重试与回退，Edge 用合成数据验证确认流程。 |

## 下一轮验证

- 核对用户能否从报告选出最值得处理的一项，并说明它对应的 JD 条件与简历证据。
- 观察用户是否会采纳一条建议修改真实经历，并用同一份 JD 复查。拖拽上传、批量采纳建议和一键生成新版简历仍待实现。

这轮材料适合用于解释产品迭代依据。当前尚无结论可用于推断用户留存、录用结果或新版的用户满意度。
