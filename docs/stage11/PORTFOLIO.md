# AI Career Copilot 作品集

**角色：项目发起人 / 产品负责人 · Codex 协作开发**

我在准备 AI 产品经理实习时发现，手里有项目和 JD，仍难判断哪些经历足以证明岗位能力，以及时间最该花在哪里。我确定了产品的首轮任务：用一份真实经历和一个目标岗位做诊断，选择一项优先差距，修改一处简历，再用同一份 JD 复查。

## 面向实习面试的讲述重点

| 面试方向 | 适合展开的内容 |
| --- | --- |
| AI 产品 | 如何从一次投递失败提出问题，选择首批用户和最小任务，设计可观察的复查指标 |
| AI Agent 产品 | 如何把需求拆成可验证的步骤，明确用户确认、工具边界、任务状态和回退。项目实现是固定工作流，可用来分析何时才有理由引入自主 Agent |
| AI 应用或智能硬件产品 | 如何把实际场景、用户问题、证据和验收标准连起来，讲清真实表现、未知项和后续验证。适用于讨论大疆等企业关注的产品实践场景，作品没有使用企业内部资料 |

## 可以出示的证据

- 当前项目的真实页面、产品需求、工作流和代码入口可直接查阅。
- 同一份 JD 的简历复查用合成账号在 Edge 实测。补充 PRD 经历后，证据支持分从 15.00 升至 30.63，报告给出新原文和剩余补写建议。[演示案例](DEMO_RESUME_REMATCH.md)
- 历史业务验收以合成数据、MySQL 与浏览器执行，外部依赖按记录受控。
- 历史真实模型使用 12 条合成样本，业务检查通过 9 条。没有真人转化率、录用提升数据或公网部署成果。
