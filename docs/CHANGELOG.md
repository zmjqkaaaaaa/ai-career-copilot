# 更新记录

## 0.9.0 · 第九阶段

- 新增求职执行工作台。可录入及收藏岗位、定制简历版本、记录投递和面试日程。
- 看板保留状态历史，并可使用投递快照进入模拟面试。新增求职统计和匿名 AI 策略报告。

## 前八阶段产品联调

- 打通推荐方案、项目仓库与对应版本面试的页面入口。
- 补齐成长诊断的来源证据，登录后驾驶舱读取本人的诊断统计。
- 登录回跳保留方案、会话和版本等查询参数。

## 0.8.0 · 第八阶段

- 新增成长中心、证据诊断、先修学习路线和时间预算。
- 新增 AI 导师、资料、版本作业、带证据的评分、阶段测评及成长报告。

## 0.7.0 · 第七阶段

- 增加五种文字模拟面试，可选择已有资料并按会话固定版本。
- 新增动态追问、面试恢复、证据评分、报告与个性化训练任务。

## 0.6.0 · 第六阶段

- 增加公开仓库导入与提交快照、只读文件树、依赖证据和 Python/JS/TS 静态索引。
- 增加架构分析、代码解释、带原文引用的知识检索和导师问答。
- 增加代码测验、逐项评分、学习自述和分版本掌握报告。

## 0.5.0 · 第五阶段

- 上线兴趣探索、痛点工作台、市场资料研究、机会评估、项目推荐和版本化 PRD。
- 新增脱敏确认、持久化工作任务、公开来源引用和 Markdown 导出。
- Tavily 搜索依赖本地密钥，补录公开资料可以单独使用。

## 0.4.0 · 第四阶段

- 新增 JD 导入、岗位解析与要求确认。
- 新增基于个人能力证据的规则评分、覆盖率、差距详情和历史报告。
- 新增经用户预览后调用百炼生成的求职建议。

## 0.3.0 · 第三阶段

- 新增私有简历文件管理、PDF/DOCX 文本解析和脱敏预览。
- 新增模型 Provider、结构化提取、版本确认、职业画像和证据状态。
- 新增文本优化与确认、任务去重和真实模型评测。

## 0.2.0 · 第二阶段

- 新增 FastAPI、SQLAlchemy、MySQL 和 Alembic 迁移。
- 新增注册、Bearer 登录、浏览器 Cookie 会话、档案查询和保存。
- React 新增登录、注册和档案流程，驾驶舱读取真实账户与档案。
- 新增真实 MySQL API 测试与 Playwright 浏览器测试。

## 0.1.0 · 第一阶段

- 初始化 React、TypeScript、Vite 和 Tailwind CSS 前端。
- 增加驾驶舱、共享布局、九个模块占位页，以及本地模块搜索和通知空状态。
- 增加示例求职概览、演示能力图和可在当前浏览器保存状态的演示任务。
- 增加项目启动、架构和测试文档。
