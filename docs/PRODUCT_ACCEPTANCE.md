# 产品端到端验收

## 第十阶段 Sprint 8

2026 年 11 月 21 日在独立 MySQL 8.4 测试库执行。主线从新注册账号开始，使用合成简历、合成岗位和经固定规则验证的 AI 样例。FastAPI、SQLAlchemy、任务状态、持久化和 Edge 页面真实运行。AI 执行由测试调用各模块的处理函数并提供受控响应。

| 场景 | 核对依据 |
| --- | --- |
| 注册、简历、画像、岗位匹配 | 确认简历内容的版本被匹配报告引用。SQL 能力保留原文证据和「用户自述」状态。 |
| 岗位、差距、项目与 PRD | 导入并收藏岗位，比较确认后的 JD 版本。探索上下文引用画像与匹配报告，首页差距与报告逐项相同。已选方案关联两版 PRD。 |
| 仓库、代码测验、掌握报告 | 导入受控公开仓库样例，确认代码文件可读。测验和掌握记录引用同一仓库提交。 |
| 模拟面试与学习路线 | 由面试日程发起模拟面试，核对投递、简历版本、岗位匹配、仓库提交和 PRD。回答形成追问和可复盘的报告，按报告更新学习路线。 |
| 投递、日程、统计 | 保存定向简历版本，更新投递状态。从驾驶舱进入同一笔投递，在浏览器保存面试结果和复盘。接口及页面都按对应简历版本统计。单条样本显示 1/1 和样本不足。 |
| 完整求职闭环与权限 | 同一账号的学习测评回写驾驶舱。第二账号读取第一账号记录会被拒绝或收到空列表。确认深链接在登录、刷新后保留。 |

离线 AI 评估 12 组样例全部通过，覆盖预设的虚构信息、越界内容和格式错误。应用主线脚本也检查评分、原文证据、报告来源及关联编号。测试不会创建真实投递或对外发送简历。GitHub 公开 API 在本机联网探测时返回配额用尽，本轮仓库链路以受控接口响应验收。真实百炼和 Tavily 未参与本轮。Docker、生产 HTTPS 和真人可用性测试仍需独立验收。

专项报告通过 `CAREER_ACCEPTANCE_REPORT` 保存到本地 `work/phase10/sprint8/final-chain.json`。同目录保留 `verified-junit.xml`、`fixture-baseline.json`、`server-performance.json` 和 `queue.json`，供核对记录 ID、输出检查与性能数据。初次全量执行的 `junit.xml` 保留了模型预览配置缺失时的失败，复测使用全新测试库和仅指向本机的占位配置。

复测先在空的测试库执行 `alembic upgrade head` 和 `alembic check`。测试 API 和 pytest 使用同一组测试库与 JWT 配置，模型占位设置为 `LLM_BASE_URL=http://127.0.0.1:9876/v1`、`LLM_MODEL=test-model` 和 `LLM_API_KEY=test-placeholder`，外部搜索密钥留空。Vite 指向隔离 API，前端地址加入测试 CORS 列表。浏览器回归的任务由测试中注入的响应驱动，复测时只启动 API 和 Vite。

性能工具使用 0、250、1,000 条合成投递，4 路并发，每个接口各发 20 个测试请求。1,000 条场景下，两个批次的 P95 分别为驾驶舱 126.38／75.07 ms、分页看板 113.27／122.86 ms、统计 459.87／256.97 ms。第二批次在全量回归完成后单独运行，原始结果见 `server-performance-recheck.json`。这些数值是本机 API 测量。独立队列模拟中，300 ms 慢任务旁的短任务，启动等待中位数为串行 300.78 ms、两路调度 1.01 ms。

## 前八阶段历史验收

验收主线使用同一个合成账号，通过公开应用接口产生业务数据。测试逐步操作注册、档案、简历上传与确认、岗位要求与匹配、项目探索与方案、代码测验、面试、学习作业和阶段测评。数据库由实际服务写入。确定性主链使用受控模型响应。真实 GitHub 变体使用同一测试流程，单独的真实模型测试检查外部推理。

## 复测方法

在开发库迁移后使用隔离测试库运行。浏览器测试指向测试 API 和测试 Vite，分别使用 8002 与 5174。真实简历浏览器测试的 API 与 Worker 必须共用独立的资料存储目录。

```powershell
$env:APP_ENV='test'
$env:DB_NAME='career_copilot_test'
Set-Location backend
& ./.venv/Scripts/python.exe -m alembic upgrade head
$env:CAREER_E2E_URL='http://127.0.0.1:5174'
$env:CAREER_ACCEPTANCE_BROWSER=$env:CAREER_E2E_URL
$env:CAREER_BROWSER_CHANNEL='msedge'
& ./.venv/Scripts/python.exe -m pytest -q tests/test_product_acceptance.py
```

`CAREER_ACCEPTANCE_LIVE_GITHUB=1` 切换为公开 yocto-queue 的真实导入。可设置 `CAREER_ACCEPTANCE_REPORT` 保存使用的测试记录 ID。默认市场研究走补录资料；Tavily 真正联网需要在本机配置密钥。
